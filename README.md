## Advanced Python Projects - TXT PARSER (beautifulsoup4, Selenium)
## 📌 Project Description
The **TXT_Parser** project is a Python-based tool designed to extract and analyze text data from external sources.  
Its main goal is to **scrape textual information from web pages or structured files**, process the data, and provide clear insights. 
The parser works with single URLs or a list of URLs . Extracted text is compared against a predefined set of tasks, and the script outputs the number of matches found.  

---

## ⚙️ Key Features
- Scrapes text from one or multiple web pages.  
- Supports input various files containing multiple URLs.  
- Compares extracted content with a predefined dataset (`leetcode-tasks.json`).  
- Outputs detailed results with number of matched tasks.  

---

## 🛠️ Technologies &  Python libraries 
- **Python 3.x**  
- **requests** – for HTTP requests  
- **beautifulsoup4** – for parsing HTML  
- **click** – for command-line interface  
- **logging** – for logging and debugging  

---

## 🚀 Usage
Example execution of the parser:
```bash
python leetcode_parser.py scrape --json-file your_json_file.json
```
